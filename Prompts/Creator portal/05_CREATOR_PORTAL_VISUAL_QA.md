# FINAL VISUAL QA — CREATOR PORTAL

## Objective

Review all four creator portal pages as one coherent product.

Pages:

- `/dashboard`
- `/collaborations`
- `/profile`
- `/contact`

## Visual consistency

Verify:

- identical sidebar;
- identical topbar;
- identical spacing system;
- consistent typography;
- consistent icon treatment;
- consistent buttons;
- consistent status badges;
- consistent form controls;
- consistent card borders;
- consistent page backgrounds.

## Color audit

The portal must NOT look pink.

Inspect the rendered UI and ensure:

### Primary

Cream / Ivory / White / Beige

### Secondary

Gold / Charcoal

### Semantic

Sage / Amber / Blue / Red only when needed

### Rose

Rose Gold / Soft Rose only as a restrained decorative accent.

If any page has excessive pink, replace it with:

- Warm Ivory;
- Sand Beige;
- Gold Light;
- Cream White;
- or neutral white.

## Design hierarchy

Check that:

- page titles are visually dominant;
- important CTAs are gold;
- navigation is clear;
- content is not cramped;
- decorative elements never compete with functional controls.

## Functional QA

Test:

- sidebar navigation;
- active navigation states;
- Visit Website;
- account dropdown;
- logout;
- dashboard cards;
- collaboration filters;
- collaboration pagination;
- profile preferences;
- save changes;
- contact forms;
- success/error states.

## Responsive QA

Verify:

- 1440px desktop;
- 1280px laptop;
- tablet;
- 390px mobile;
- 360px mobile.

Check for:

- horizontal overflow;
- clipped buttons;
- broken tables;
- unusable forms;
- overlapping decorative elements.

## Accessibility QA

Verify:

- keyboard navigation;
- visible focus;
- labels;
- button names;
- form errors;
- contrast;
- reduced-motion compatibility where animations exist.

## Engineering QA

Run:

- lint;
- formatter;
- type check;
- unit/component tests;
- integration tests where available;
- production build.

Fix issues rather than suppressing them.

## Completion requirement

The four pages should look like one premium Arika Creator Portal, not four independently designed screens.
